# CodSoft: To-Do List Application

A functional command-line interface (CLI) To-Do List application developed for the CodSoft Python Programming internship. This tool allows users to efficiently manage daily tasks with features for adding, updating, and tracking completion status.

## Key Features

- **Create Tasks:** Add new items to your list with a single command.
- **Track Progress:** Mark tasks as completed `[x]` or pending `[ ]` to keep track of your productivity.
- **Update Logic:** Edit existing task descriptions without having to delete and re-add them.
- **Delete Functionality:** Remove tasks that are no longer relevant.
- **Data Persistence:** All tasks are automatically saved to a local `todo.txt` file so your list is preserved between sessions.

## Project Specifications

- **Language:** Python 3.x
- **Storage:** Flat-file system (`todo.txt`)
- **UI:** Interactive Command-Line Interface
